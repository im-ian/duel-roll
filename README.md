# ROLL//DUEL

방 코드로 친구와 바로 대결하는 모바일 우선 2인 주사위 전략 게임이다. 모든 주사위 굴림과 규칙 판정은 서버가 담당하며, 클라이언트는 서버 스냅샷만 화면에 반영한다.

## 아이디어 출처

이 프로젝트는 스마일게이트 RPG의 MMORPG **로스트아크에 등장하는 주사위 미니게임 `티카투카`를 모방하고, 2인용 웹 PVP로 재해석해 만든 비공식 팬 프로젝트**다. 세 라인에 주사위를 배치하는 방식, 같은 눈을 모으는 점수 체계, 상대 주사위를 제거하는 알까기, 실드 주사위와 타짜 등의 핵심 아이디어에서 영향을 받았다.

로스트아크 및 티카투카의 상표·저작권은 각 권리자에게 있으며, 이 프로젝트는 스마일게이트 RPG와 제휴하거나 공식적으로 승인받은 프로젝트가 아니다. 원작의 로고, 캐릭터, 이미지, 음원 및 UI 자산은 사용하지 않고 독자적인 이름과 시각 자산으로 제작했다.

## 실행

요구 환경은 Node.js 24 이상과 pnpm 11이다.

```bash
pnpm install
pnpm dev
```

- 웹: `http://127.0.0.1:5173`
- 서버: `http://127.0.0.1:3001`
- 두 개의 브라우저 프로필 또는 일반/시크릿 창으로 방 생성과 참가를 시험할 수 있다.

프로덕션 빌드를 로컬에서 확인하려면 다음을 실행한다.

```bash
pnpm build
pnpm preview
```

이때 웹과 API, WebSocket은 모두 `http://127.0.0.1:3001`에서 제공된다.

## 현재 구현

- 3라인 × 5슬롯 보드와 눈 중복 점수
- 시작 실드, 일반 배치, 알까기, 보너스 실드
- 경기당 1회 타짜, 홀드, 항복, 승패 판정
- 교환·눈 변환 인벤토리와 턴당 아이템 1개 제한
- 6자리 방 생성·참가와 두 플레이어 준비
- 서버 CSPRNG와 서버 권위 명령 처리
- `expectedVersion` 동시성 검사와 `actionId` 멱등성
- `HttpOnly` 좌석 쿠키와 해시된 서버 세션
- WebSocket presence, 전체 스냅샷 복구, 미확정 명령 재전송
- 모바일/태블릿/데스크톱 반응형 UI
- 결과 집계와 양쪽 동의 재대결

## 구조

```text
src/game       I/O 없는 순수 규칙 엔진
src/server     방·좌석 세션·명령·WebSocket 서버
src/protocol   클라이언트/서버 메시지 계약
src/client     React 모바일 우선 UI
tests          규칙 및 서버 통합 테스트
docs           규칙·아키텍처·UX 명세
```

설계 기준은 [문서 인덱스](./docs/README.md), 세부 규칙은 [게임 규칙 명세](./docs/game-rules.md)를 참고한다.

## 검증

```bash
pnpm test
pnpm typecheck
pnpm build
```

현재 테스트는 5슬롯 용량과 점수, 아이템 교환·양쪽 주사위 변환·턴당 제한, 규칙 상태 전이, 방 수명주기, 세션 쿠키, 명령 중복·버전 충돌, 타짜 후보 비공개, 재대결을 다룬다.

## 현재 운영 한계

방과 좌석 세션은 개발용 메모리 저장소를 사용하므로 서버 재시작 시 사라진다. 턴 자동 행동, 90초 재접속 유예 뒤 몰수패, 방 만료·참가 속도 제한, 영속 DB는 다음 운영 단계에서 추가해야 한다. 현재 클라이언트는 같은 서버 프로세스 안의 일시적인 연결 끊김과 새로고침은 복구한다.
