# Roll the Dice 문서

이 디렉터리는 방 코드로 두 사람이 대결하는 모바일 퍼스트 주사위 웹 게임의 초기 제품·기술 명세다. 로스트아크의 티카투카 규칙을 조사 기준으로 삼되, 인간 PVP에 필요한 동작을 별도 제품 규칙으로 고정하고 공개 서비스 자산은 독자적으로 제작한다.

## 문서 읽는 순서

1. [게임 규칙 명세](./game-rules.md): 보드, 점수, 알까기, 실드, 타짜, 인벤토리, 홀드, 종료, 승패와 필수 테스트를 정의한다.
2. [아이템 명세](./items.md): 8종 카탈로그, 기본 지급, 공통 제한, 개별 효과와 명령·UI 매핑을 정의한다.
3. [방 코드 PVP 아키텍처](./pvp-architecture.md): 서버 권위 모델, 방·좌석 세션, 상태 머신, 명령 계약, 재접속, 저장과 테스트 전략을 정의한다.
4. [모바일 퍼스트 UX](./mobile-first-ux.md): 화면 구조, 단계별 조작, 네트워크 복구, 접근성, 반응형 QA를 정의한다.

## 문서의 우선순위

같은 내용을 여러 문서에서 언급하다 충돌하면 다음 순서로 해석한다.

1. 게임의 합법성·점수·승패: `game-rules.md`
2. 아이템 카탈로그·기본 지급·효과 요약: `items.md`
3. 서버 상태·명령·인증·동시성: `pvp-architecture.md`
4. 화면 배치·문구·연출·접근성: `mobile-first-ux.md`

UI는 규칙을 바꿀 수 없고, 네트워크 계층은 규칙 엔진을 우회할 수 없다.

| 주제 | 결정 |
| --- | --- |

| 제외 | 계정, 랭킹, 매칭, 관전, 채팅, 베팅·티카투카 선언 |

## 원작 규칙과 제품 규칙

`game-rules.md`는 각 결정을 다음처럼 구분한다.

- **원작 확인**: 인게임 규칙·실제 플레이·복수 자료가 일치한 동작
- **프로젝트 결정**: 인간 PVP에서 모호함 없이 실행되도록 이 프로젝트가 고정한 동작
- **추후 원작 검증 가능**: 공개 자료만으로 완전히 확정되지 않았지만 MVP 동작은 프로젝트 정책으로 정한 부분

첫 버전에서 의도적으로 제외했거나 아직 원작 확인이 필요한 항목은 `game-rules.md`의 `MVP 제외 및 미확정 항목`을 기준으로 한다.

원작 재현 여부가 불확실한 동작을 몰래 가정하지 않는다. PVP 규칙을 바꿀 때는 명세, 엔진 테스트, UI 설명을 함께 갱신한다.

## 현재 구현 선택

- React 19 + Vite 클라이언트와 Fastify WebSocket 서버를 한 TypeScript 저장소에서 운영한다.
- 규칙 엔진은 서버·React와 분리된 순수 모듈로 유지한다.
- 서비스명과 시각 체계는 독자적인 `ROLL//DUEL` 브랜드를 사용한다.
- 로컬 MVP 저장소는 메모리이며, 운영 DB와 배포 환경은 아직 선택하지 않았다.
- 방 보존 기간, 턴 자동 행동, 재접속 유예 몰수패는 운영 단계에서 구현·조정한다.

이 선택과 무관하게 서버 권위, 방 코드와 좌석 인증 분리, 버전·멱등성, 순수 규칙 엔진 경계는 유지한다.

## 권장 구현 순서

1. 점수 함수와 규칙 불변 조건
2. 스크립트 RNG를 쓰는 상태 머신과 규칙 테스트
3. 네트워크 없는 로컬 2인 시뮬레이터
4. 방 생성·코드 참가·좌석 세션
5. 명령 버전·멱등성과 영속 저장
6. WebSocket 이벤트·스냅샷
7. 모바일 게임 화면
8. 재접속·presence·서버 타이머
9. 재대결·운영 지표

## 변경 규칙

- 규칙을 바꾸면 `game-rules.md`의 예시와 필수 테스트를 먼저 갱신한다.
- 새 명령이나 단계를 만들면 아키텍처의 명령 표, 상태 모델, 오류 계약을 갱신한다.
- 단계가 바뀌면 모바일 UX의 단계별 상호작용과 연결 끊김 QA를 갱신한다.
- 영속 경기 로그를 도입할 때는 당시 규칙 식별자를 로그 메타데이터에 함께 저장해 서로 다른 통계를 분리한다.
- 원작 출처로 새 동작을 확정하면 조사 기준일과 근거 링크를 남긴다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 라인 | 각 플레이어 보드의 3개 점수 구역 중 하나 |
| 슬롯 | 한 라인 안의 최대 5개 표시 위치. 일반 배치에는 개별 위치 선택 의미가 없지만 아이템은 놓인 주사위를 직접 선택함 |
| 일반 주사위 | 자기 보드에 놓고 알까기로 제거될 수 있는 주사위 |
| 실드 주사위 | 점수에는 포함되지만 알까기로 제거되지 않는 주사위 |
| 알까기 | 현재 일반 주사위를 소모해 상대 같은 라인의 동일 눈 일반 주사위를 제거하는 행동 |
| 타짜 | 현재 눈과 새 후보 중 하나를 고르는 경기당 1회 행동 |
| 주사위 교환 | 같은 라인의 내 주사위와 상대 주사위를 하나씩 골라 1:1로 바꾸는 아이템 |
| 눈 변환 | 양쪽 보드 중 주사위 하나를 골라 다른 무작위 눈으로 바꾸는 아이템 |
| 무작위 투하 | 양쪽 보드의 무작위 빈칸에 무작위 일반 주사위를 하나씩 추가하는 아이템의 가칭 |
| 주사위 파괴 | 양쪽 보드 중 일반 주사위 하나를 골라 제거하는 아이템 |
| 주사위 리롤 | 현재 착수할 일반 주사위를 다른 무작위 눈으로 다시 굴리는 아이템 |
| 홀수·짝수 주사위 | 현재 일반 주사위를 선택한 홀짝의 다른 무작위 눈으로 바꾸는 아이템 |
| 홀드 | 현재 주사위를 버리고 남은 자기 턴을 영구 포기하는 행동 |
| 항복 | 점수와 무관하게 즉시 패배하는 행동 |
| 스냅샷 | 특정 버전의 전체 권위 게임 상태 |
| presence | WebSocket 연결·재접속 상태. 규칙 상태와 분리됨 |
