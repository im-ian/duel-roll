# 아이템 명세

- 상태: 현재 구현 기준선
- 문서 버전: 1.1
- 최종 검토: 2026-07-27

이 문서는 `ROLL//DUEL`의 아이템 카탈로그, 기본 지급 정책, 사용 조건과 UI·서버 계약을 한곳에서 확인하기 위한 아이템 전용 문서다. 규칙의 최종 판정 기준은 [게임 규칙 명세](./game-rules.md), 네트워크 payload는 [PVP 아키텍처](./pvp-architecture.md), 상세 조작 흐름은 [모바일 퍼스트 UX](./mobile-first-ux.md)를 따른다.

## 1. 현재 카탈로그와 기본 지급

아이템 카탈로그에는 여덟 종류가 등록되어 있다. 새 게임에서는 이 중 네 종류만 각 1개씩 지급한다.

| 아이템 | 내부 타입 | 기본 지급 | 대상 | 핵심 효과 |
| --- | --- | ---: | --- | --- |
| 주사위 교환 | `SWAP` | 0 | 같은 라인의 양쪽 보드 일반 주사위 1개씩 | 두 주사위 전체를 1:1 교환 |
| 눈 변환 | `REROLL` | 0 | 어느 보드든 배치된 일반 주사위 1개 | 현재 눈과 다른 무작위 눈으로 변경 |
| 실드 강화 | `SHIELD` | 1 | 현재 착수할 일반 주사위 | 눈과 ID를 유지하고 실드로 강화 |
| 무작위 투하(가칭) | `DROP` | 0 | 양쪽 보드의 빈 슬롯 | 양쪽에 무작위 일반 주사위 1개씩 추가 |
| 주사위 파괴 | `DESTROY` | 1 | 어느 보드든 배치된 일반 주사위 1개 | 선택한 주사위 제거 |
| 주사위 리롤 | `TURN_REROLL` | 0 | 현재 착수할 일반 주사위 | 현재 눈과 다른 무작위 눈으로 다시 굴림 |
| 홀수 주사위 | `ODD` | 1 | 현재 착수할 일반 주사위 | 현재 눈과 다른 무작위 홀수 눈으로 변경 |
| 짝수 주사위 | `EVEN` | 1 | 현재 착수할 일반 주사위 | 현재 눈과 다른 무작위 짝수 눈으로 변경 |

따라서 현재 새 게임의 기본 인벤토리는 다음 네 개다.

- 실드 강화 ×1
- 주사위 파괴 ×1
- 홀수 주사위 ×1
- 짝수 주사위 ×1

기본 수량이 0인 아이템도 카탈로그와 인벤토리 UI에는 `×0`으로 표시된다. 게임별 보상 라인을 먼저 완성하면 여덟 종류 전체 중 하나를 무작위로 획득할 수 있으므로, 기본 지급이 0인 아이템도 경기 중 사용할 기회가 생긴다.

## 2. 공통 사용 규칙

- 현재 플레이어의 `TURN_ACTION`에서만 사용할 수 있다.
- 한 턴에는 종류와 관계없이 아이템을 최대 하나만 사용할 수 있다.
- 서버가 명령을 승인한 순간 수량을 1 차감하고 `itemUsedThisTurn`을 `true`로 바꾼다.
- 잘못된 대상이나 사용할 수 없는 단계의 명령은 상태와 수량을 바꾸지 않는다.
- 아이템 사용만으로 턴은 끝나지 않는다. 사용 후 바뀐 상태에서 합법한 일반 배치, 알까기, 타짜 또는 홀드를 계속할 수 있다.
- 다음 턴이 시작되면 `itemUsedThisTurn`은 다시 `false`가 된다. 같은 플레이어가 연속 턴을 받아도 새 턴이면 다시 아이템을 사용할 수 있다.
- `TAZZA_CHOICE`, `BONUS_PLACEMENT`, 상대 턴과 종료된 경기에서는 사용할 수 없다.
- 예외적으로 무작위 투하가 어느 보드의 15번째 칸을 채우면 양쪽 투하를 모두 적용한 뒤 경기를 즉시 종료한다.
- 보상 라인에서 받은 아이템은 인벤토리에 즉시 더해진다. 지급 자체는 아이템 사용 횟수에 포함되지 않지만, 이미 이번 턴 아이템을 사용했다면 새 아이템도 다음 턴부터 사용할 수 있다.

## 3. 실드 면역

모든 `SHIELD` 주사위는 공통 `isDieEffectImmune` 판정을 사용한다.

- 주사위 교환, 눈 변환, 주사위 파괴의 보드 대상이 될 수 없다.
- 주사위 리롤, 홀수 주사위, 짝수 주사위로 현재 실드의 눈을 바꿀 수 없다.
- 실드 강화는 현재 주사위가 이미 실드라면 사용할 수 없다.
- 향후 맵 효과도 같은 면역 판정을 사용해야 한다.
- 실드도 배치된 보드의 점수에는 일반 주사위와 동일하게 포함된다.

## 4. 아이템별 세부 규칙

### 주사위 교환

1. 내 보드의 `NORMAL` 주사위 하나를 선택한다.
2. 상대 보드의 같은 라인에 있는 `NORMAL` 주사위 하나를 선택한다.
3. 두 주사위의 눈, ID, 종류와 생성자 정보를 포함한 전체 객체를 서로 교환한다.
4. 선택한 두 위치만 서로 대체하며 같은 라인의 나머지 주사위 순서는 유지한다.
5. 교환 뒤 점수는 각 주사위가 새로 위치한 보드에 귀속된다.

라인 자체를 바꾸거나 한쪽 주사위만 옮기는 효과가 아니다.

### 눈 변환

- 이미 보드에 놓인 내 주사위 또는 상대 주사위 하나를 고른다.
- 현재 눈을 제외한 나머지 다섯 눈 중 하나를 균등하게 선택한다.
- `id`, `kind`, `createdBy`, 보드와 라인은 유지하고 `face`만 바꾼다.

### 실드 강화

- 현재 착수 대기 중인 `NORMAL` 주사위에만 사용한다.
- `id`, `face`, `createdBy`를 유지하고 `kind`만 `SHIELD`로 바꾼다.
- 강화된 주사위는 알까기를 실행할 수 없지만 원하는 내 빈 라인에 배치할 수 있다.

### 무작위 투하(가칭)

- 내 보드와 상대 보드에서 각각 남은 빈 슬롯 하나를 균등하게 선택한다.
- 각 보드에 서로 독립적인 공정한 d6 결과의 `NORMAL` 주사위를 하나씩 추가한다.
- 빈칸이 많은 라인은 남은 슬롯 수만큼 선택 확률이 높다.
- 두 배치는 하나의 원자적 효과다. 어느 한쪽이 15칸을 채워도 다른 쪽 투하까지 적용한 뒤 종료를 판정한다.
- 투하 주사위의 `createdBy`는 아이템 사용자이며, 점수는 실제 배치된 보드에 귀속된다.

### 주사위 파괴

- 이미 보드에 놓인 내 `NORMAL` 주사위 또는 상대 `NORMAL` 주사위 하나를 제거한다.
- 제거 직후 보드 점수를 다시 계산한다.
- 홀드한 플레이어의 주사위를 제거해 빈칸이 생겨도 그 플레이어의 홀드는 해제되지 않는다.

### 주사위 리롤

- 이미 배치된 주사위가 아니라 현재 착수할 `NORMAL` 주사위가 대상이다.
- 현재 눈을 제외한 나머지 다섯 눈 중 하나를 균등하게 선택한다.
- `id`, `kind`, `createdBy`는 유지하고 `face`만 바꾼다.
- 승인된 새 눈은 롤링 애니메이션으로 공개한다.

`눈 변환`과 이름이 비슷하지만 대상이 다르다. 눈 변환은 **보드에 놓인 주사위**, 주사위 리롤은 **현재 착수할 주사위**에 사용한다.

### 홀수·짝수 주사위

- 현재 착수할 `NORMAL` 주사위에만 사용한다.
- 홀수 주사위는 `1, 3, 5`, 짝수 주사위는 `2, 4, 6`에서 결과를 고른다.
- 현재 눈이 선택한 홀짝 후보에 포함되어 있으면 그 눈을 제외한다. 따라서 성공하면 눈은 반드시 달라진다.
- `id`, `kind`, `createdBy`는 유지하고 `face`만 바꾼다.

## 5. 명령과 이벤트

| 아이템 | 클라이언트 명령 | 성공 이벤트 |
| --- | --- | --- |
| 주사위 교환 | `USE_SWAP_ITEM` | `DICE_SWAPPED` |
| 눈 변환 | `USE_REROLL_ITEM` | `DIE_REROLLED` |
| 실드 강화 | `USE_SHIELD_ITEM` | `DIE_SHIELDED` |
| 무작위 투하 | `USE_DROP_ITEM` | `DICE_DROPPED` |
| 주사위 파괴 | `USE_DESTROY_ITEM` | `DIE_DESTROYED` |
| 주사위 리롤 | `USE_TURN_REROLL_ITEM` | `TURN_DIE_REROLLED` |
| 홀수·짝수 주사위 | `USE_PARITY_ITEM` + `ODD` 또는 `EVEN` | `TURN_DIE_PARITY_CHANGED` |
| 보상 라인 지급 | 서버의 배치 후 자동 판정 | `LINE_REWARD_CLAIMED` |

클라이언트는 아이템 결과를 먼저 계산하지 않는다. 서버가 명령의 단계, 수량, 턴당 제한, 대상과 실드 면역을 검증하고 확정 스냅샷과 이벤트를 전송한다.

## 6. 인벤토리 UI

- 행동 영역의 아이템 버튼은 현재 보유 수량의 합계를 표시한다. 새 게임에서는 `4개`다.
- 인벤토리 sheet에는 카탈로그의 여덟 종류를 모두 표시한다.
- 수량 0은 `보유 수량 없음`, 이번 턴에 이미 사용했다면 `이번 턴 사용 완료`, 합법 대상이 없다면 대상이 없는 이유를 표시한다.
- 주사위 교환은 내 주사위 선택 후 같은 라인의 상대 주사위를 선택한다.
- 눈 변환과 주사위 파괴는 양쪽 보드에서 합법 대상만 직접 선택할 수 있다.
- 실드 강화, 무작위 투하, 주사위 리롤, 홀수·짝수 주사위는 별도 보드 대상 선택 없이 즉시 명령을 보낸다.
- 서버 응답을 기다리는 동안 다른 입력을 잠그고, 승인 뒤 대상 선택 모드를 닫는다.
- 보상 라인 배너에서 획득 아이템을 알리고, 이후 인벤토리 버튼의 합계와 해당 카드 수량에 서버 스냅샷 값을 반영한다.

## 7. 카탈로그와 지급 설정

아이템 등록과 기본 지급은 의도적으로 분리되어 있다.

```ts
ITEM_TYPES = [
  "SWAP",
  "REROLL",
  "SHIELD",
  "DROP",
  "DESTROY",
  "TURN_REROLL",
  "ODD",
  "EVEN",
]

STARTING_ITEM_TYPES = ["SHIELD", "DESTROY", "ODD", "EVEN"]
```

- `ITEM_TYPES`를 바꾸면 상태 타입, 불변 조건, UI 카드, 프로토콜과 테스트를 함께 갱신한다.
- `STARTING_ITEM_TYPES`만 바꾸면 새 게임의 기본 인벤토리가 달라진다.
- 보상 라인은 `ITEM_TYPES` 전체에서 같은 확률로 하나를 뽑아 서버 권위 전이로 수량을 늘리고 `LINE_REWARD_CLAIMED` 이벤트를 남긴다.

### 보상 라인 지급

- 새 게임마다 세 라인 중 하나를 균등하게 보상 라인으로 정한다.
- 어느 보드든 해당 라인에 주사위 3개를 먼저 채우면 카탈로그 여덟 종류 중 하나를 균등하게 지급한다.
- 일반 착수, 알까기 보너스 실드, 무작위 투하로 추가된 주사위를 모두 센다. 실드는 효과의 대상이 되는 것이 아니라 목표 진행도에 포함되는 것이므로 면역 규칙과 충돌하지 않는다.
- 한 경기의 보상은 한 번만 지급한다. 무작위 투하로 양쪽이 동시에 조건을 만족하면 서버가 두 플레이어 중 한 명을 균등하게 선택한다.
